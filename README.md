# Aura English Atelier — Sea

A bespoke, luxury English language training web application for **Aura English Atelier**, Pallavaram, Chennai.

## Features
- **Hero Section**: Interactive 3D clay alphabet physics engine, animated dynamic pedagogic carousels, and luxury frosted floating navigation.
- **Boutique Cohorts (Section 2)**: 5 bespoke course cards with 120 FPS GPU-accelerated center-stack to fan-out scroll animations and interactive 3D mouse tilt.
- **Learn With Us (Section 3)**: Editorial blog and masterclass section with signature Ocean Blue accents (`#009DC4`), floating badges, and an interactive reading drawer modal.
- **Course Dossier Modal**: Comprehensive curriculum breakdown, 4-phase syllabus modal with dedicated clean scrollbar.

## Running Locally

To launch the static web server on port 3001:

```bash
# Direct node execution
node ui/server.js
```

Or run the batch script:
```bash
./start-ui.bat
```

Open your browser at `http://localhost:3001`.
